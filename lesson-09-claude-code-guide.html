Claude Code: первый простой инструмент

В этом уроке заходим в Claude Code и собираем первый понятный инструмент: веб-анализатор сайта с точки зрения маркетинга и SEO. Ниже лежит сам рабочий промпт и ссылки на сервисы, которые упоминались в уроке.

Открыть видео Назад к уроку

Что собираем

  • Простой веб-инструмент для разбора сайта с точки зрения маркетинга и SEO.
  • Инструмент, куда пользователь вставляет URL и получает понятный разбор.
  • Локальную MVP-версию, которая живет на вашем компьютере и может использовать вашу подписку Claude там, где это нужно.

Промпт для Claude Code

Собери простой веб-инструмент для разбора сайта с точки зрения маркетинга и SEO.

Пользователь вставляет ссылку на страницу, а инструмент показывает:
- заголовок страницы
- meta description
- h1 и h2
- оффер страницы
- CTA
- есть ли проблемы с SEO
- есть ли слабые места в упаковке
- 5 рекомендаций: что улучшить в тексте, структуре и видимости страницы

Нужен простой красивый интерфейс без лишнего.
Это должен быть понятный мини-инструмент, который выглядит как полезный рабочий сервис, а не как сырая тех-демка.
Сделай MVP и подготовь к локальному запуску.
