01

Свои команды Терминал

Повторяющийся процесс можно превратить в собственную команду: научите Claude один раз — дальше запускаете одним словом, не объясняя заново. Идеально для шагов, которые вы делаете постоянно (черновик поста, разбор, ресёрч).

/ваша-команда
Команда создаётся обычным текстовым файлом в папке .claude/skills/ вашего проекта.
Документация Claude Code
02

Отчёт о вашей работе Терминал

Claude анализирует ваши прошлые сессии и собирает отчёт: над чем вы работали, какой у вас стиль, что получается, а что тормозит. А команда расхода показывает стоимость сессии и лимиты вашего плана.

/insights   /usage
/insights — большой разбор вашей работы. /usage — расход токенов и лимиты.
Документация: расход и лимиты
03

Сколько контекста осталось Терминал

Живая карта: что прямо сейчас занимает «память» диалога — системные инструкции, прочитанные файлы, подключённые инструменты. Видно, где перегруз, и Claude подсказывает, что почистить.

/context
Чтобы цифра висела постоянно — настройте статус-строку: /statusline
Документация: контекстное окно
04

Шаг назад во времени Терминал

Перед каждым изменением файла Claude делает снимок. Если что-то пошло не так — двойное нажатие Esc откатывает и код, и переписку на шаг назад. Одно нажатие Esc просто останавливает Claude.

Esc · Esc
Это локальные контрольные точки сессии, отдельно от Git.
Документация Claude Code
05

Голосовой ввод Терминал

Режим «нажми и говори»: удерживаете пробел, проговариваете задачу, отпускаете — Claude расшифровывает и выполняет. Удобно, когда проще сказать, чем напечатать.

/voice
После команды удерживайте пробел и говорите. Доступно на платных планах.
Документация Claude Code
06

Вставить файл одним символом Терминал

Напишите @ и имя файла или папки прямо в сообщении — Claude сразу увидит содержимое, не тратя время на поиск. Работает и с файлами, и с целыми папками.

@имя-файла.md
Начните вводить @ — появится список файлов для выбора.
Документация: рабочие сценарии
07

Картинка вместо описания Терминал Браузер

Перетащите изображение в окно или вставьте через Ctrl+V — Claude разбирает скриншоты, макеты, схемы, ошибки. Показали дизайн или ошибку картинкой — получили разбор.

Перетащить файл · Ctrl + V
В терминале вставка — именно Ctrl+V, не Cmd+V.
Документация: работа с изображениями
08

Переключение режимов Терминал

Без команды переключаете, насколько Claude самостоятелен: спрашивать каждый раз → принимать правки автоматически → режим плана (сначала показывает план, потом делает). Режим плана — отличный способ увидеть ход мысли до того, как Claude тронет файлы.

Shift + Tab
Нажимайте Shift+Tab во время сессии, чтобы переключать режимы по кругу.
Документация Claude Code
09

Сжать диалог с умом Терминал

Когда переписка разрослась, эта команда ужимает старое и освобождает контекст. Главное — можно указать, что сохранить, и Claude не выбросит важное.

/compact оставь только [тема]
Без уточнения /compact сожмёт по своему усмотрению.
Документация Claude Code
10

Память, которую не нужно повторять Терминал Браузер

Claude хранит контекст о вас и читает его перед каждой задачей — не нужно объяснять себя заново. В терминале это команда /memory. В браузере claude.ai — раздел «Память» в настройках, плюс «Поиск по прошлым чатам»: после включения можно попросить «опиши меня по всем нашим диалогам», и Claude соберёт ваш портрет.

/memory
Быстро дописать факт в терминале — начните строку с символа #. В браузере: Настройки → Профиль → «Поиск по прошлым чатам».
Документация: память
С чего начать

Если фишек много — начните с трёх: /context (видеть загрузку диалога), двойной Esc (откат назад) и @файл (быстро дать Claude нужное). Остальное подключайте по мере привычки.

Большинство команд работают в Claude Code — это версия в терминале (нужен план Pro или выше). Картинки и память работают и в браузере на claude.ai.
